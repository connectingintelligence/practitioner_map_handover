What the mixing actually costs

Option B is not Bebas Neue. It is Bebas Neue for 131 groups and Oswald for 18, and a reader has no way to know why. Oswald is the closest widely available match, and it is still a different design: different stroke weight, different width, a lowercase where Bebas has none. Set beside each other in one list, the Ukrainian circles will read as a different class of thing.

That is the part worth weighing. Eighteen of these groups are run by Ukrainian facilitators during a war. The map already leaves their names and descriptions untranslated, deliberately, so they appear in their own words. Having them also appear in a visibly different typeface is a small thing, and it points the wrong way.

Where Bebas Neue does work

The map's own furniture is all Latin and all short: the title, the three counters, the section headings. Bebas Neue there is straightforward, follows the brand, and never meets a Cyrillic character. That is option B applied only to the chrome, with group names in Open Sans, and it is the version I would suggest if the brand change is firm.

On the 102 character name

Noah is right that this is the other problem. Bebas Neue has no lowercase, so that name is set in all caps whatever we do. In the map's card it runs to four lines and is genuinely hard to read. Option C keeps sentence case and stays legible at every length.
